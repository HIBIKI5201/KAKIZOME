# KAKIZOME

## AssetStoreTools（サブモジュール）

`Assets/AssetStoreTools` は private リポジトリ [KAKIZOME_AssetStoreTools](https://github.com/HIBIKI5201/KAKIZOME_AssetStoreTools) をサブモジュールとして参照している（閲覧権限が必要）。クローン時にサブモジュールも取得する。

```bash
git clone --recurse-submodules https://github.com/HIBIKI5201/KAKIZOME.git
# クローン済みの場合
git submodule update --init
```
